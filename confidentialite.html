Règles de confidentialité

Application d'envoi des courriels de Lou Darques. En vigueur le 21/10/2026.

1. Qui est responsable

Lou Darques, seul utilisateur et seul responsable de l'application. Contact : louisdarques+genealogie@gmail.com.

2. Les données Google auxquelles l'application accède

L'application demande un seul droit sur Gmail : https://www.googleapis.com/auth/gmail.send, qui permet d'envoyer un courriel au nom du titulaire du compte. Elle demande aussi l'adresse du compte (openid, email), pour vérifier que le compte autorisé est bien celui de Lou Darques.

Elle ne lit, ne liste et ne télécharge aucun courriel, aucun contact, aucun agenda, aucun fichier de Google Drive. Le droit accordé ne le permet pas.

3. Comment ces données sont utilisées

  • Les courriels envoyés sont rédigés par Lou Darques (ou préparés pour Lou Darques) et partent de son propre compte, vers les destinataires choisis pour chaque dossier.
  • Le jeton d'accès délivré par Google est gardé sur l'ordinateur de Lou Darques seulement, dans un fichier que seule sa session peut lire. Il n'est copié nulle part ailleurs.
  • L'application garde, sur ce même ordinateur, un registre de ses envois (date, destinataires, objet, identifiant rendu par Gmail), pour ne jamais envoyer deux fois le même courriel.

4. Partage, vente, transfert

Aucune donnée obtenue par les API de Google n'est vendue, louée, partagée ou transférée à un tiers, ni utilisée pour de la publicité, ni pour entraîner un modèle d'intelligence artificielle, ni pour évaluer la solvabilité de quiconque. Aucun humain autre que Lou Darques n'y a accès.

5. Conformité

L'usage des informations reçues des API de Google respecte la Google API Services User Data Policy, y compris ses exigences d'usage limité (Limited Use).

6. Durée de conservation et suppression

Le jeton est gardé tant que Lou Darques utilise l'application. Il peut être retiré à tout moment depuis la page des accès de son compte Google ; le fichier du jeton est alors supprimé de l'ordinateur. Le registre des envois est gardé aussi longtemps que les dossiers auxquels ces courriels se rapportent.

7. Modification

Toute modification de ces règles est datée sur cette page.
